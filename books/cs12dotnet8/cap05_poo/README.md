# Capítulo 05 - Construindo Tipos com Programação Orientada a Objetos

## Membros de um objeto
- Campos (Fields): armazenam data, são variáveis que pertencem ao objeto
- - Constant
- - Read-only
- - Event
- Métodos (Methods): são instruções e funções dentro de objeto
- - Constructor
- - Property
- - Indexer
- - Operator
